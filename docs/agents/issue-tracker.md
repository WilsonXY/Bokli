# Issue tracker

Local markdown is the tracker for Bokli. Spec and tickets live as files under `.scratch/bokli/` in this repo.

- Spec: `.scratch/bokli/spec.md`
- Tickets: one file per ticket under `.scratch/bokli/issues/<NN>-<slug>.md`, numbered from `01` in dependency order.

No `gh` calls, no remote issues. See `to-tickets` local-ticket template for shape.
